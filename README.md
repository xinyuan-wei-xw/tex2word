# Tex/PDF to Word

Convert LaTeX projects and scanned PDFs into clean, editable Word documents.

- **Mode A — LaTeX project → Word**: upload the whole project as a `.zip`
  (`.tex`, `.bib`, figures, compiled PDF) → high-fidelity `.docx`
  (text, math as OMML, tables, citations, figures).
- **Mode B — Scanned PDF → Word**: OCR (English + 简体中文) → clean,
  structured `.docx` with detected headings.

Built for [Xinyuan's Toolbox](https://xinyuan-wei-xw.github.io/).
